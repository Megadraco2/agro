# Produto

Objetivo: SaaS de gestão agrícola com web responsiva e instalação PWA em dispositivos móveis.

Escopo entregue: infraestrutura, diagnóstico de API e base de desenvolvimento.
Fora do escopo: cadastros, produção agrícola, estoque, finanças, cobrança e quaisquer fluxos de negócio.

Antes da próxima fase, levantar usuários, operações, limites de organizações, conectividade no campo e prioridades.
Definir critérios de acessibilidade, navegadores suportados e requisitos de implantação com os responsáveis pelo produto.
